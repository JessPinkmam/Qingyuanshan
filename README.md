## Muse / Codex 归档约定

新增或更新报告时，按以下步骤维护目录。

1. 阅读 HTML 的标题和正文，按 `domain → category → topic` 确定三级分类。跨境电商的二级分类使用喷泉、Light、耳环等品类，跨品类内容归入通用选品，三级填写具体研究方向。优先复用现有分类和标签。
2. 将报告 HTML 及其依赖资源提交到本仓库，确认页面内的相对链接和图片路径可以访问。
3. 在 [reports.json](reports.json) 中登记元数据。`id` 为稳定的唯一标识，`path` 为仓库相对路径，`title` 使用页面实际标题，`domain`、`category`、`topic` 依次表示三级分类，`tags` 支持跨分类检索，`summary` 概述内容，`updated_at` 记录报告实际更新日期，格式为 `YYYY-MM-DD`。
4. 更新已有报告时，按 `path` 找到原记录，保留原 `id`，更新内容、标签和日期。同一 HTML 对应一条记录。每篇报告归入一个三级分类，其他相关方向补充到标签中。
5. 在本 README 对应的三级方向中补充或更新在线阅读链接、简介、标签和源码链接，并核对报告数量、索引覆盖范围及本地文件是否一致。新增分类时同步更新目录分组。

索引中的初始更新时间取自每个 HTML 最近一次 Git 提交的日期。在线阅读地址以 `https://jesspinkmam.github.io/Qingyuanshan/` 为基础，拼接报告的相对路径。
