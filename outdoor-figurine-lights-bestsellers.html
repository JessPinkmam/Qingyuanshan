🧩 头部公式拆解：Nacome 为什么能霸榜

  • 主角选“慢萌动物”：乌龟、青蛙是前两名。它们不挑审美、不吓人、男女老少都觉得可爱，而且和“花园、慢生活”天然搭。
  • 第二功能 = 多肉盆：背上 / 怀里能放一盆多肉，白天是摆件，买家还会自己换植物、拍照晒单，等于自带 UGC。
  • 光点集中不散：7 颗 LED，不是一串灯带。光集中在多肉周围 / 造型轮廓，夜景照片一眼能看懂。
  • 标题就是搜索词 + 送礼词：Solar Garden Statues + 动物 + Succulent + 7 LED Lights + Patio / Balcony / Yard + Gifts for Mom Grandma Women，一行把搜索、场景、送礼全占了。
  • 价格卡在 $14–28：送礼不心疼、自用不犹豫的区间。超过 $30 就要靠“大尺寸 / 成套 / 特殊造型”讲故事。

⚠️ 避坑：这个类目死在哪三件事上

1. 灯不亮 / 进水 = 头号死因。太阳能板朝向、电池、密封圈，任何一个拉垮，差评都会集中在“不亮、进水”。防水至少做到 IP44，头部地插款做到 IP65；详情页要写清“白天晒够 6–8 小时、晚上亮 6–10 小时”，别承诺 12–14 小时那种极端值。

2. 尺寸与照片不一致 = 头号退货源。“smaller than expected” 是这类目最常见的差评。主图必须放参照物（手、花盆、门廊台阶），尺寸用英寸 + 厘米双标，9–12 英寸是 yard 款的安全区，太小只能走桌面 / 迷你套装。

3. 白天不好看 = 没有复购和晒单。买家白天先看脸：树脂做工、涂装、上色不均，白天就输了。夜景图要拍“黄昏花坛里的光”，不要只拍黑夜里的光点。

  • 3–6 月：花园季 + 母亲节，是全年主旺季，送礼标题要前置 Mom / Grandma。
  • 11–12 月：圣诞 + 乔迁礼物季，适合成套、礼盒装。
  • 全年：Housewarming / Birthday 是常驻送礼词，不要只押一个节日。
